# خرمدین | KHORRAMDIN

وبلاگ فارسی کتاب برای برند خرمدین — نسخهٔ کدنویسی‌شده و حرفه‌ای‌تر وبلاگ مرجع
(khorramdin.blogsky.com). پروژه مدرسه‌ای؛ بدون فروشگاه، بدون بک‌اند.
ساخته‌شده با React ،TypeScript ،Vite ،Tailwind CSS و Lucide React.

## ساختار وبلاگ

- صفحه اصلی: هیرو سرمه‌ای + فهرست یادداشت‌ها + سایدبار (جستجو، جدیدترین‌ها، ابر برچسب، بایگانی، راه‌های ارتباطی)
- صفحه مطلب: `/post/:slug` — یادداشت‌های «محصولات» (معرفی کتاب‌ها) و «نحوه سفارش»
- عناوین مطالب: `/posts` — آرشیو با جستجو (`?q=`)، فیلتر برچسب (`?tag=`) و بایگانی ماه (`?month=`)
- درباره ما: `/about`
- تماس با ما: `/contact`

## اجرای محلی

```bash
npm install
npm run dev
```

سایت روی `http://localhost:5173` باز می‌شود.

## بیلد و پیش‌نمایش

```bash
npm run build
npm run preview
```

خروجی بیلد در پوشه `dist` قرار می‌گیرد.

## دیپلوی روی Render (Static Site)

ریپازیتوری شامل `render.yaml` است؛ ساده‌ترین راه:

1. در Render گزینه **New → Blueprint** را بزنید و ریپازیتوری GitHub را انتخاب کنید.
2. Render به‌صورت خودکار سایت استاتیک را با این تنظیمات می‌سازد:
   - Build Command: `npm ci && npm run build`
   - Publish Directory: `dist`
   - Rewrite: `/* → /index.html` (برای مسیریابی SPA)
   - Node Version: `22.12.0`

روش دستی: **New → Static Site** را بزنید، ریپو را وصل کنید و مقادیر بالا را وارد کنید؛
سپس در بخش **Redirects/Rewrites** قانون `/* → /index.html` از نوع Rewrite را اضافه کنید.

## ویرایش محتوا

- یادداشت‌ها (عنوان، تاریخ، برچسب‌ها، خلاصه): `src/data/posts.ts`
- کتاب‌های یادداشت محصولات (عنوان، نویسنده، دسته، توضیح، جلد): `src/data/books.ts`
- اطلاعات تماس و ساعات کاری (فعلاً نمونه): `src/data/site.ts`
- تصاویر جلدها و بنر: `public/images/`
- فونت پینار (وزن‌های Regular/Medium/Bold به‌صورت woff2): `public/fonts/`

همهٔ جلدها عکس واقعی کتاب‌ها هستند (`public/images/books/`)؛ جلد «شازده کوچولو» از Open Library تهیه شده است.
اگر بارگذاری هر جلد شکست بخورد، یک جلد جایگزین هم‌خوان با برند نمایش داده می‌شود.
